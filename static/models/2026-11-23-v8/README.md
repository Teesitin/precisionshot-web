# PrecisionShot V8 target enclosure

Ten enclosure parts from plates 01–08 of the V8 print map.
This set uses the original R12 hollow-post grid and R3 M3 faceplate.

- The assembled STEP, STL, and OBJ show the parts in their installed positions.
- The STEP folder contains the ten individual CAD solids in their V8 positions.
- The STL folder contains the original print-oriented meshes.
- The OBJ folder contains the same triangles and print orientations as the STLs.
- Coordinates are in millimeters. If your OBJ importer asks for units, select millimeters.
